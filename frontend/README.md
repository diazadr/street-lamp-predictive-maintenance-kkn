# Street Lamp Predictive Maintenance — Frontend

Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + next-intl (ID/EN).
Struktur mengikuti frontend MANGO: `src/app` (routing), `src/features/<fitur>/{components,hooks,services,schema,views}`,
`src/components/{layouts,providers,ui}`, `src/lib/http`.

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
npm install
npm run dev                  # http://localhost:3000
```
